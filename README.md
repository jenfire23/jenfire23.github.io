# README

Dieses Repository ist ein Teil eines Abschlussprojekts in Form eines Datenbankprojekts.
Es stellt eine Website zur Verfügung, auf der die Werte einer Datenbank grafisch dargestellt werden können.

Die Website ist öffentlich verfügbar.
Um die Datenbank sowie verschiedene Daten zu schützen, gelangen nur gewünschte Informationen in dieses Repository.
Da es für diese Website mit entsprechendem Funktionsumfang ausreicht, 
werden die Werte von SQLite in JSON umgewandelt und automatisiert in diesem Repository hochgeladen.
Dadurch ist es nicht möglich, an sensible Daten aus der ursprünglichen Datenbank zu gelangen.
